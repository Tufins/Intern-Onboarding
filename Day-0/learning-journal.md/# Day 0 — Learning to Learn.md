## Day 0 — Feynman Check

**Concept:** Active Learning

Active learning means taking part in the learning process instead of only receiving information. For example, watching someone solve a programming problem is like watching a driving lesson, while solving the problem yourself is like getting behind the wheel and practising. When I practise, recall what I learned, and explain it in my own words, I can identify what I genuinely understand. If I only watch demonstrations and memorise answers, I might struggle to solve a similar problem independently.
